Microsoft Research와 Dartmouth, Columbia 팀의 RWML은 전문가 데이터도, 더 강한 LLM도, 태스크 성공 리워드도 없이 에이전트의 월드 모델을 RL로 학습하는 방법임. 핵심은 하나임. 환경에서 관측한 (상태, 행동, 다음 상태) 트리플릿으로 다음 상태를 예측하게 하고 임베딩 유사도 기반 이진 리워드로 GRPO(같은 프롬프트에서 여러 응답을 뽑아 서로 비교해 업데이트하는 그룹 기반 RL 알고리즘) 학습하는 것임.

1. 문제 설정. LLM 에이전트는 언어 과제는 잘하는데 "내가 이 행동을 하면 환경이 어떻게 바뀌는가"를 예측하는 능력이 약함. 사전학습 목표(정적 텍스트 next-token prediction)와 에이전트 환경의 요구가 어긋나서임.

2. 기존 해법 둘의 문제. 전문가 궤적 SFT(정답 예시에 대한 지도 학습 파인튜닝)는 전문가 데이터나 강한 LLM 생성 데이터가 필요해서 확장성과 비용이 걸림. 태스크 성공 리워드 RL은 정확한 성공/실패 신호가 필요한데 희소하고 설계가 어려움. 그리고 SFT로 다음 상태를 맞추는 WM SFT 접근은 토큰 수준 충실도가 우선되다 보니 의미적 동치를 놓치고 모델 붕괴로 이어질 수 있음.

3. RWML의 데이터는 자기 자신으로 만듦. 대상 모델로 환경에 N번 롤아웃(ALFWorld, 텍스트 가상세계에서 집안일 과제로 에이전트를 평가하는 벤치마크, N=3; τ² Bench, 고객 응대 시나리오로 도구 사용을 평가하는 벤치마크, N=6)해서 얻은 궤적을 전부 트리플릿으로 쪼갬. 리워드는 이진임. 예측 다음 상태와 실제 다음 상태의 임베딩 코사인 거리가 임계값 이하면 1점, 아니면 0점. 기존 임베딩 모델을 그대로 씀. 이게 리워드 전부임.

![RWML 개요](/images/2026-09-04-rwml-reinforcement-world-model-learning/fig-2-p3.png)

4. 디테일 두 개가 붙음. 첫째, too-easy 필터링. 별도 SFT 모델이 10회 시도해서 계속 맞추는 샘플은 p=0.1 확률로만 남김. 두 벤치마크 모두 약 30%가 easy로 걸러졌고 이걸 빼면 성능이 떨어짐. 너무 쉬운 문제로 학습 낭비를 막는 것임. 둘째, 이진 리워드. 연속값 LLM-as-a-judge보다 reward hacking에 더 강하다는 게 실증됐고 부록에 판정 모델을 속여 통과하는 사례가 나옴.

5. 결과. ALFWorld(Qwen2.5-7B)에서 base 13.0, RWML 단독 32.6(+19.6), Policy RL 단독 81.0, RWML+Policy RL 87.9(+6.9). τ² Bench(Qwen3-8B)도 31.9→38.8→43.7로 같은 패턴임. 성공 리워드 없이 "다음 상태를 맞췄는가" 신호만으로 이만큼 오른다는 게 핵심임.

![주요 결과](/images/2026-09-04-rwml-reinforcement-world-model-learning/table-1-p5.png)

6. 대조가 흥미로움. WM SFT 단독은 ALFWorld 2.8로 base(13.0)보다 못함. RL 신호와 SFT 신호의 격차가 이만큼 크다는 뜻임. 그리고 전문가 데이터 기반 방법들과 비교하면 ALFWorld에선 전문가 주석 방법보다 위, τ² Bench에선 전체 2위임. 외부 감독 없이 이 숫자면 충분함.

![전문가 데이터 비교](/images/2026-09-04-rwml-reinforcement-world-model-learning/table-2-p5.png)

7. 왜 잘 되는가의 증거 세 개. 첫째, forgetting이 적음. 학습 후 MMLU-Redux(지식 질의응답), IFEval(지시 이행 능력), MATH-500(수학 문제 해결) 같은 벤치마크를 다시 측정했는데 WM SFT 대비 거의 모든 항목에서 하락이 작음. 온라인 RL의 on-policy 성질 때문이라는 해석에 동의함.

8. 둘째, 파라미터 업데이트가 작음. 레이어별 weight change ratio에서 RWML은 WM SFT보다 훨씬 적은 파라미터만 건드림. 그래서 이후 Policy RL을 얹을 때 간섭이 적어서 조합이 잘 됨. SFT-then-RL이 아니라 RL-then-RL 구조라 안정적이라는 게 요지임.

9. 셋째, 무효 행동이 줄어듦. 명시적으로 학습한 적 없는데 ALFWorld의 형식 오류·불필요한 look/examine이 59.30%→39.45%, τ² Bench의 없는 툴 이름·잘못된 인자가 24.90%→8.84%로 약 1/3이 됨. 환경을 이해하니 행동이 정확해지는 것임. 우리가 보는 에이전트의 무효 툴콜 문제가 월드 모델 부족에서 온다는 증거로 읽을 수 있음.

![forgetting 측정](/images/2026-09-04-rwml-reinforcement-world-model-learning/table-3-p6.png)

10. 실무 채점. 이 논문의 포지션은 mid-training임. 사전학습과 태스크 RL 사이에 self-supervised로 환경 역학을 주입하는 단계를 하나 끼워 넣는 것임. 리워드 설계가 임베딩 코사인 + 이진화로 끝나서 확장 비용이 낮음.

11. 커스텀 환경에서 에이전트를 돌릴 때 성공 리워드를 정의하기 애매하다면 "다음 관측 예측" 신호로 먼저 학습시키는 루트가 현실적 대안이 됨. 그리고 LLM-as-a-judge 리워드를 쓰는 파이프라인이라면 이진화 판정으로 바꾸는 것만으로 reward hacking 리스크를 줄일 수 있다는 증거로 쓸 만함.

12. 한계. 약한 베이스 모델은 전이가 안 됨. τ² Bench에서 Qwen2.5-7B는 월드 모델 지식을 의사결정으로 옮기지 못했고 Qwen3-8B/30B-A3B는 큰 폭 상승함. 최소 이상의 베이스 역량이 전제조건임. 텍스트 상태 환경 한정이라 시각/물리 환경 확장은 미검증임.

13. 그래도 결론은 실용적임. 환경 이해라는 추상적 목표가 "다음 상태 예측 이진 리워드"라는 조립 가능한 형태로 제시됐다는 것. 태스크 RL 앞에 끼워 넣을 수 있는 저렴한 전처리 단계로 자리 잡을 가능성이 있음.
