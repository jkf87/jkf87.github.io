TOFU(가상 인물 정보 삭제 과제)나 MUSE(책·코드 도메인 지식 삭제 과제) 같은 기존 언러닝 벤치마크는 모델의 최종 답변만 읽고 잊었는지 판정함. 근데 에이전트로 배포하면 그 판정이 안 통함. [K-Bench](https://arxiv.org/abs/2609.12808)는 ReAct(생각-행동-관찰을 반복하는 표준 에이전트 루프) 에이전트가 노출하는 6개 채널(CoT 즉 답하기 전 사고 과정, 도구 호출, 도구 관측, 검색, 최종 답변, 요약)을 전부 검사해서 하나라도 비밀이 나오면 누수로 처리함. 핵심 숫자가 뼈아픔. 프롬프트나 검색 저장소에 비밀이 있을 때 TOFU/MUSE는 누수 0을 보고하는데 배포된 에이전트는 같은 설정에서 22%에서 86%까지 쿼리에서 비밀을 흘림. 정보가 사라지는 게 아니라 채널을 옮겨 다닌다는 것.

1. 문제의 예시가 직관적임. "Robert Gill의 생년월일은?" 질문에 답변 채널만 지우는 언러닝 메서드(StaR)를 적용하면 최종 답변에 날짜가 없어서 답변만 읽는 평가는 "잊었다"고 판정함. 근데 도구 관측 채널을 보면 검색 결과 원문에 날짜가 그대로 남아 있고 에이전트 흐름 안에서 회수 가능함. 특정 채널만 타깃하는 방어는 그 채널을 비우지만 비밀이 타깃 밖 채널로 옮겨가면 관측자의 집계 누수율은 그대로라는 것. 보안 검사의 범위를 어디까지 볼 것인가가 실질적으로 누수율을 결정한다는 오래진 교훈의 에이전트 버전임.

![전체 구조](/images/2026-09-14-kbench-agent-unlearning/fig-1-p1.png)

2. 실험 설계가 깔끔함. 비밀을 정확히 한 곳에만 넣고 테스트함. 가중치(파라메트릭 메모리), 프롬프트(컨텍스트), 검색 저장소(비구조 텍스트 / 구조화 인덱스) 세 곳. 기질별로 어떤 채널로 누수가 나는지 분리해서 볼 수 있어서 채널 마이그레이션이 그대로 관측됨. 구조화 검색에서 도구 관측 채널에 비밀이 verbatim으로 남는 사례가 대표적이라는 것.

3. 가중치에 비밀이 있는 경우는 더 단순하게 나쁨. 평가된 공개 언러닝 메서드 20개 중 관측자 기준으로 검증된 지식 제거에 도달한 사례가 없었음. 선택적 잊기를 달성한 건 input-corruption 개입 하나뿐. refusal-tuning 계열은 평가된 추출 공격에는 저항하는 편인데 지식 제거 검증은 없음. 언러닝을 배포 후 안전장치로 쓰고 있다면 전제 자체를 다시 봐야 한다는 것.

![채널 마이그레이션 측정](/images/2026-09-14-kbench-agent-unlearning/fig-6-p17.png)

4. K-Score 설계의 교훈 하나. 누수율에 더해 forget 억제, retain 보존, 에이전트 안정성을 같이 봄. activation editing 계열이 누수를 줄이는 것처럼 보였는데 실제로는 에이전트가 붕괴해서 아무것도 못 하는 경우였음. 붕괴하면 비밀도 안 나오니 누수율만 보면 "성공"으로 읽힘. K-Bench는 이걸 실패로 처리함. "안전해졌다"와 "못 하게 됐다"를 구분하지 않는 평가는 무너진 시스템을 성공으로 채점한다는 것. 앞서 정리한 OSReward(관대함 편향)와 정확히 대칭되는 반대 방향 편향임.

![에이전트 붕괴 측정](/images/2026-09-14-kbench-agent-unlearning/fig-7-p17.png)

5. 리더보드 관행 문제도 지적함. 최상위 메서드가 베이스 모델에 따라 바뀜. Llama에서 1등인 방법이 Qwen에서는 아님. 단일 모델 리더보드는 메서드×모델 상호작용을 하나의 점수로 오려내서 보여준다는 것. 이건 언러닝뿐 아니라 내 스킬·프롬프트 벤치마킹에도 그대로 적용되는 경고임. 하나의 모델에서 낸 순위를 일반화하지 말 것.

6. 실무 관점 메모 세 개. 첫째, 언러닝의 성공 판정은 답변 채널 기준으로는 부족하고 CoT, 도구 로그, 검색 결과까지 증거 범위를 넓혀야 함. 둘째, RAG 시스템에서 검색 인덱스 자체에 PII(개인 식별 가능 정보)가 들어가면 모델 수준 언러닝은 애초에 잘못된 도구이고 인덱스 정리나 접근 제어가 먼저임. 셋째, 프롬프트에 넣은 민감정보는 세션 종료 시 파기 대상이지 모델 언러닝의 적용 범위가 아님. 지울 대상을 채널별로 구분해두는 정책 문서가 먼저라는 것. 정보는 흐르고 차단은 채널 단위로만 유효하다는 게 이 논문의 한 줄임.
