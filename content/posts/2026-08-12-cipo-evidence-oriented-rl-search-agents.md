검색 에이전트를 RL로 훈련하면 골치 아픈 버릇이 생김. 검색은 하긴 하는데 결과를 안 읽고 자기 사전 지식으로 먼저 결론을 내린 다음 검색은 확인용으로만 쓰는 것. prior-driven reasoning이라 부르는 이 패턴이 쌓이면 확인 편향이 됨. 검색은 확인용이고 증거가 추론을 바꾸는 일은 없어짐. 문제는 기존 보상이 이걸 못 잡는다는 것. 최종 정답만 맞으면 보상이 그대로 나감. CIPO는 "검색 결과를 실제로 참고했는지"를 직접 측정해서 보상으로 만든 프레임워크임.

1. 측정 방법이 깔끔함. 검색 결과가 보일 때와 가렸을 때 다음 추론 액션의 생성 확률을 비교하는 것. 어텐션 마스크로 검색 결과 토큰에 대한 어텐션만 차단함. 토큰을 삭제하거나 교체하는 게 아니라서 시퀀스 길이, 위치 인덱스, 이전 컨텍스트가 전부 유지됨. 두 조건의 log-likelihood 차이를 토큰 수로 나눈 값이 EALR. 양수면 검색 결과가 다음 액션 확률을 높였다는 뜻, 즉 증거를 참고함. 0에 가까우면 안 읽는다는 뜻임. 외부 보상 모델도 사람 라벨도 필요 없음.

![CIPO 전체 아키텍처](/images/2026-08-12-cipo-evidence-oriented-rl-search-agents/fig-2-p3.png)

2. 보상 결합이 원칙적임. EALR 보상은 각 검색 후 추론 턴에, outcome 보상은 최종 정답 턴에 각각 그룹 내 정규화를 하고 할인 누적 리턴으로 합침. γ=1.0을 썼고 EALR은 훈련 중에만 계산해서 추론 때 추가 비용이 없음. 보상 설계 분석이 이 논문의 뼈대를 보여줌. EALR만 쓰면 증거 반응성은 오르는데 무관 증거 사용률도 같이 오름(31.7%). Outcome과 결합하면 관련 증거 사용률은 55~61%로 더 오르면서 무관 증거 사용률은 9~11%로 떨어짐. 두 보상이 상호보완적이라는 측정임. "증거를 봐라"와 "정답을 맞혀라"를 같이 줘야 한다는 것.

3. 성능 결과. Qwen2.5-3B와 7B로 4개 사전학습 도메인과 3개 외부 도메인에서 평가. 7B 기준 GRPO 0.405, GiGPO 0.409, IGPO 0.457인데 CIPO 0.504. IGPO 대비 +4.7 F1. 3B에서도 일관되게 최고. 두 모델 크기 모두에서 이겼다는 게 방법의 일반성을 보여줌.

4. 확인 편향 감소가 진짜 성과임. IGPO는 훈련이 진행될수록 prior-driven rate이 올라감. 정답을 맞추는 샘플에서도 그런데, 이게 곧 "맞히긴 하는데 검색이 허혈루팬이 된다"는 뜻. CIPO는 반대로 꾸준히 감소함. 전체 증거 기반 추론 비율이 IGPO 29.9% → CIPO 41.9%, 정답 궤적에서는 59.4% → 70.2%로 오름. 숫자가 맞는 이유가 좋아진다는 게 실무적으로 중요함. 지식만으로 맞히는 에이전트는 분포가 바뀌면 무너지니까.

![Prior-driven rate 비교](/images/2026-08-12-cipo-evidence-oriented-rl-search-agents/fig-4-p6.png)

5. 비용이 합리적임. EALR 계산 때문에 턴별로 evidence-masked scoring 패스가 한 번 더 필요한데 7B에서 오버헤드 4.63%에 F1 개선 17.48%. 3B에서도 오버헤드 9.17% 대비 개선 12.00%. 개선 대비 비용 비율이 좋고 추론 시엔 추가 비용이 없음.

6. 내 실무 이식은 이렇게임. 첫째, RAG 에이전트 평가에 "증거가 추론을 바꿨는가" 지표를 넣을 것. EALR 계산은 훈련 없이도 진단 도구로 쓸 수 있음. 검색 결과를 마스크했을 때 답이 안 바뀌면 검색이 장식이라는 뜻. 둘째, 보상은 목적 신호(outcome)와 과정 신호(EALR)를 결합할 것. 과정만 주면 무관 증거에도 반응하고 목적만 주면 확인 편향이 생김. 셋째, attention masking으로 인과 효과를 재는 패턴은 다른 컨텍스트 컴포넌트(예: 시스템 프롬프트, 이전 턴 요약)의 실제 기여 측정에도 이식 가능함. 한계는 짚을 것. 단일 검색 도구만 테스트했고 γ=1.0이라 긴 궤적에서 크레딧이 흐려질 수 있음. 코드가 공개되어 있어 재현 장벽은 낮음.
