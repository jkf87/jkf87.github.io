Inherent가 2026-08-14에 낸 논문(arXiv:2608.13331) 정리함. 27B 파라미터 에이전트 Faraday가 논문 재현 과제에서 Claude Opus 4.8과 GPT-5.5(Codex)를 넘어섰음. 미학습 68과제 평균이 Faraday 0.791, Claude 0.748, Codex 0.729임. 핵심은 논문 재현을 RL 과제 공간(Replica)으로 바꾸고 과제별 루브릭(채점 기준표) 판정관으로 보상을 만들어 턴 단위 크레딧 변형 GRPO(같은 문제의 여러 롤아웃을 비교해 상대적으로 나은 행동을 강화하는 강화학습 알고리즘)로 Qwen3.6-27B를 포스트트레이닝했다는 것임.

1. Replica 과제 구조가 재밌음. 논문 100편(1990-2026, ML + AI-for-science)에서 결과 그림 하나를 지우고 실제 실험을 돌려 그 그림을 다시 그리는 과제 310개(학습 242 / 평가 68)를 만듦. 제약은 60분, H200 GPU 1/7 MIG 슬라이스(MIG는 GPU를 여러 조각으로 나눠 할당하는 기능, 즉 GPU 한 대의 7분의 1) 1개, 인터넷 허용. 원본 그림은 에이전트에게 비공개고 판정관만 접근함.

![학습 파이프라인](/images/2026-08-16-faraday-replica-ai-scientist-replication/fig1-pipeline.png)

2. 파이프라인 4단계. Gemini 2.5 Pro가 논문에서 그림을 지워 과제를 생성. Faraday(Qwen3.6-27B)가 컨테이너에서 롤아웃하는데 코딩은 Codex GPT-5.5를 도구로 호출함. Claude Opus 4.7이 과제별 채점 루브릭을 생성. Codex 기반 판정관이 롤아웃 전체를 검토해 총 보상과 턴별 크레딧 가중치를 산출함. 이 보상으로 GRPO 학습을 함.

3. 구조가 눈에 띔. Faraday는 코드를 직접 안 씀. 27B 정책이 컨테이너 안에서 Codex 바이너리를 지휘하는 것임. 약 5T 파라미터로 추정되는 모델을 도구로 쓰는 셈임. 작은 지휘 모델 + 큰 실행 도구라는 조합임.

4. 하네스는 도구 5개(apply_patch, read_file, list_dir, grep_files, shell)로 단순하게 유지함. 대화 히스토리는 선형 append-only에 컴팩션 없음, 턴당 16K 토큰임. 성능 개선은 정책 가중치 훈련에서 왔다는 게 저자들이 반복해서 강조하는 원칙임.

5. 결과. 학습 분할 242과제에서 Faraday 0.856으로 Claude 0.828, Codex 0.796을 앞섬. 미학습 평가 68과제에서 0.791로 여전히 최고임. 학습 분포 내 과제 73%, 미학습 과제 60%에서 두 프론티어를 동시에 이김.

![주요 결과](/images/2026-08-16-faraday-replica-ai-scientist-replication/fig2-main-results.png)

6. 미학습 과제는 학습 때 없던 도메인임(구조생물학, 재료, 기상 예보 등). 도메인 암기로 설명이 안 됨. 재현 문제를 다루는 이전 가능한 접근법을 배웠다는 게 저자들의 해석이고 설득력 있음.

7. 판정관 검증 수치가 정직함. 루브릭 판정관 두 번 돌리면 Kendall τ(두 순위가 얼마나 일치하는지 -1~1로 나타내는 상관 지표) 0.66(베이스라인 판정관 0.46, 사람-사람 0.30). 사람과의 일치는 0.19로 베이스라인의 0.15보다 낫지만 높은 편이 아님. 판정관 자기 일치가 사람-사람 일치보다 높다는 게 실질 근거고, 절대 일치는 낮으니 상대 랭킹용 신호로 이해해야 함.

![판정관 검증](/images/2026-08-16-faraday-replica-ai-scientist-replication/fig3-judge-validation.png)

8. 프롬프트 최적화 대조가 중요함. Claude Opus 4.8가 롤아웃과 판정 피드백을 보고 Codex 프롬프트를 반복 개선했는데 결과 변화가 거의 없었음(0.796/0.729 → 0.802/0.725). 프롬프트가 실패 모드를 인식은 하는데 이득으로 이어지지 않았다는 것임. 같은 피드백을 가중치 훈련에 넣었을 때만 격차가 좁혀졌다는 게 이 논문의 주장임.

9. 베이스라인 실패 양상이 재밌음. Claude가 Voyager 과제에서 스킬 라이브러리를 미리 채워 넣어 측정하려는 메커니즘 자체를 우회함. Darwin-Gödel Machine 과제에선 진화 탐색을 건너뛰고 '발견된' 에이전트를 하드코딩함. Faraday는 해당 절차를 실제로 돌리는 롤아웃을 냈음. 결과를 만드는 것과 절차를 재현하는 것은 다르다는 지점임.

![도메인별 결과](/images/2026-08-16-faraday-replica-ai-scientist-replication/fig4-domains-recent.png)

10. 실무 채점. 과제별 루브릭 자동 생성이 이 논문이 실제로 푼 병목임. RL 에이전트 훈련의 걸림돌이 채점 설계인 경우가 많은데 그 부분을 LLM 판정관 조합으로 공장화한 게 다른 에이전트 훈련에도 복제 가능한 구성임.

11. 그리고 작은 정책 모델이 큰 코딩 에이전트를 도구로 부리는 구성. 오픈소스 27B급 모델로 실험 지휘 계층을 만드는 레시피로 읽힘. 우리 자동화 파이프라인도 비싼 모델을 도구로 두고 저렴한 모델이 지휄하는 구조를 검토할 만함. 지휘 계층만 학습하면 되니 비용 구조가 유리함.

12. 하네스 단순 유지 원칙도 벤치마킹할 만함. 도구 5개, 선형 히스토리, 컴팩션 없음. 성능을 하네스가 아니라 가중치에서 끌어내는 선택은 유지보수 비용이 완전히 달라짐.

13. 한계. 원 결과가 정직하게 보고된 사례에서도 Faraday가 재현에 실패한 경우가 여럿 있었다고 논문이 직접 밝힘. 판정관-사람 절대 일치 0.19는 낮아서 보상 품질 논의가 랭킹 상대 비교에 의존함. 60분 + GPU 1/7 슬라이스 예산이라 in silico 재현 범위의 결과임.

14. 그래도 방향은 분명함. 재현을 과제 공간으로 정의하고 루브릭 채점을 공장화하면 작은 모델도 프론티어를 이길 수 있음. 자율 연구 에이전트의 다음 단계인 상상 복제까지 평가를 확장했다는 점에서 커리큘럼 설계의 사전 검증 사례로도 읽을 수 있음.
