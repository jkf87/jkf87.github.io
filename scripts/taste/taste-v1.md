# 코난쌤 블로그 취향 규칙 v1 (2026-10-08)

출처: 코난쌤이 Opus가 다듬은 글(컨텍스트 압축 라운드업)을 직접 고친 내용과, 같은 규칙으로 다시 쓴 두 번째 글(중단 판단 라운드업)을 "품질 괜찮다"고 확인한 결과다. 승인된 예시 글은 이 폴더의 `example-owner-approved-*.md` 두 편이다. 쓰기 전에 한 편을 읽고 말투를 맞춘다.

`scripts/blog-taste-gate.py <post>`가 필수 규칙을 검사한다. 실패하면 고치고 다시 돌린다.

## 필수 (게이트가 막음)
1. 본문은 존댓말로 쓴다. "~습니다"를 기본으로 하고 "~죠", "~구요", "~요"를 섞는다. 평서 "~다"는 5% 이하. 예외: 결론 목록 맨 앞의 굵은 단언문은 "~다"로 쓴다 (예: **첫 번째 압축에서 맥락을 가장 많이 잃어버린다.**).
2. "구요"는 코난쌤 말투다. "고요"로 고치지 않는다.
3. 화자는 "제가"다. "블로그봇이/블로그봇은"을 쓰지 않는다. 직접 확인 절 제목은 `## 제가 직접 확인한 것`.
4. 마지막 문장은 그대로 쓴다: `이 글은 제가 여러 자료를 비교·정리하고 일부는 에이전트를 활용해 실행하고 확인한 내용으로 발행하였습니다.`
5. 맞춤법: "이였" → "이었", "되요" → "돼요", 마침표 두 번 금지.

## 권장 (게이트가 알려 줌)
6. "~습니다"만 이어지지 않게 "~죠/~구요/~요"를 10% 이상 섞는다.
7. 지표·연구 용어(AUROC, FDR, Δ, 컨포멀, pp 등)는 처음 나올 때 풀어 쓰거나 현상 말로 바꾼다. 예: "손해(dU@3)" → "맥락을 잃어버린다", FDR → "틀린 답 비율".
8. 기술 현상에 "아프다" 같은 몸 비유를 쓰지 않는다. 핵심 발견 한두 곳에는 일상어 강조를 써도 된다 (예: "잘 돌고 있던 에이전트가 맥락을 잃어버리고 바보가 됐어요").
9. 직접 확인 절은 과정을 이야기로 쓴다. 해 본 것, 못 한 것, 느낀 점 한 줄 (예: "찾아봤는데 … 아쉽게도 재현은 못 했습니다", "직접 세어 보니 더 실감이 나더라구요").
10. 도입부는 독자가 겪는 문제부터 쓴다 (예: "검색이 헛도는데도 멈추지 않고 예산을 다 태우는 경우가 있죠").
11. 강조(형광펜)는 결론과 숫자에만 5~14곳.
12. "충격적인", "곤두박질", "반전 결말", "토큰 폭탄" 같은 과장과 "A가 아니라 B" 틀을 쓰지 않는다.
