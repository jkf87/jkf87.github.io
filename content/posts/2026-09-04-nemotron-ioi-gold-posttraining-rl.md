IOI 2026에서 AI 시스템이 처음으로 인간 최고 득점자를 넘겼다는 논문이 나옴. 인간 참가자와 동일한 시간·인터넷 차단·제출 제한 조건이었다는 게 의미가 커서 정리함. 원문은 [arXiv:2609.02849](https://arxiv.org/abs/2609.02849).

1. 결과부터. NVIDIA의 Nemotron-3-Ultra-CC가 535.4/600점으로 인간 최고 득점자 498.27점을 넘김. 다만 비공식·무감독 평가라 순위엔 포함 안 됨. 파이프라인은 데이터 큐레이션 → SFT → RL(Nano만) → GenCorrect 테스트타임 루프 4단계임.

2. 큐레이션 단계가 기초임. 20년치 대회에서 22,000문제를 모으고 각 문제를 문제 설명·제약·테스트케이스·레퍼런스 정답을 갖춘 실행형 평가 환경으로 패키징함. 레퍼런스 정답과 생성 정답의 판정이 일관할 때만 남기고 평가 문제는 전부 제외·중복 제거함. 검증 통과 환경만 쓴다는 원칙이 뒷단계 신뢰성의 기반임.

3. SFT가 게인의 대부분을 만듦. DeepSeek-V4-Flash로 Nano용 120만 트레이스, Ultra용 47만 트레이스를 생성해서 어려운 문제에 배분을 늘리고 "이전 풀이를 고치는" 자기개선 트레이스도 포함함. Nano 기준 IOI 2025 Score@1이 21.7→47.3%. 게인 대부분이 첫 에폭에서 나옴.

4. RL의 기여는 작지만 일관적임. GRPO + 실행 기반 바이너리 보상으로 47.3→48.5%. 논문 설명이 흥미로운데 바이너리 보상 GRPO는 롤아웃 그룹에 성공·실패가 섞여야 학습 신호가 생겨서 모델 능력 경계 근처 문제에만 작동한다는 것. 그리고 SFT 없이 베이스에서 바로 RL을 돌리면 24.9%에 그쳐서 SFT가 주는 능력을 RL이 대체 못 한다는 결론. 예산이 한정되면 강한 베이스 + 소규모 SFT가 작은 모델의 대규모 포스트트레이닝보다 낫다는 게 4.3절 정리임.

5. GenCorrect가 금메달을 만든 장치임. 최대 5라운드의 닫힌 루프 — 최대 200개 후보를 병렬 생성해 로컬 컴파일, 행동 기반 클러스터링으로 점수 보기 전에 다양한 대표 10개 선택, 10개 제출 후 서브태스크 점수 피드백을 다음 라운드에 반영. 결과가 Nano 360.6→468.2, Ultra 343.9→502.0. 1라운드 343.9점이던 모델이 루프 5번으로 502점이 된 것 — 인간 최고점을 넘는 데 가장 큰 기여는 모델이 아니라 테스트타임 컴퓨트와 선택 전략이었다는 뜻임.

6. 실전 세부 선택들도 배울 만함. 교사 모델은 점수도 높고 출력이 짧아 고정 시간에 후보를 더 뽑을 수 있는 GLM-5.2로 골랐고, 마지막 라운드엔 생성 예산을 1,000개로 늘리고 모델에게 테스트 생성기·검증기·스코어링 스크립트를 직접 만들게 해서 실행 기반으로 상위 10개를 골랐음. NVFP4 양자화로 Score@1 6.6점을 주고 처리량 3.7배를 얻어 큰 후보 배치를 돌린 트레이드오프도 실전적임.

7. 필자 해석. 이 논문에서 가져갈 것 두 가지. 첫째, 실행 보상 RL을 기획할 때 SFT 데이터 품질이 우선이라는 측정 — 에이전트 RL 붐에서 자주 잊히는 사실임. 둘째, GenCorrect는 결국 "생성 → 실행 검증 → 피드백 반영" 하네스 루프를 제출 예산 안에 최적화한 설계라서, 코드 외에도 실행 검증이 가능한 모든 영역에 적용 여지가 있음. 필자의 게이트-재시도 구조가 같은 뼈대라는 점에서 방향 확인이 됨.

8. 문제제기. 760 GPU 규모 추론 인프라가 전제된 결과라 재현 문턱이 높음. IOI 2026 런이 단일 비공식 평가라 반복 안정성은 일반 파이프라인 5회 반복(521.72±25)으로만 뒷받침됨. 그리고 경쟁 코딩이라는 검증 친화적 도메인 특성이 다른 도메인으로의 확장을 보장하진 않음.

9. 남는 결론. 실행 검증기가 있는 도메인에서는 모델 크기보다 검증 환경 품질과 테스트타임 루프 설계가 순위를 바꿈. 액티브 3B짜리 Nano-CC가 베이스 Ultra(550B)를 넘겼다는 사실이 그 요약임.
