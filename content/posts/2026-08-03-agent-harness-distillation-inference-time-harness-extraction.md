에이전트 하네스가 곧 지적 재산임. Baidu·Tsinghua가 제시한 Agent Harness Distillation(AHD)은 블랙박스 상호작용만으로 자율 다중 에이전트 시스템의 추론 시간 하네스를 추출해 다른 에이전트로 전이할 수 있음을 최초로 실증함. 하네스에 투자한 수개월 엔지니어링이 정교한 프롬프트 몇 번으로 새어나갈 수 있다는 뜻임.

1. 배경부터. Claude Code, Hermes 같은 자율 다중 에이전트 시스템은 작업이 들어올 때마다 추론 시간 하네스를 동적으로 만듦. 계획, 도구 사용, 협업, 컨텍스트 조립, 메모리 관리가 전부 하네스가 결정함. 조달, 도구 오케스트레이션, 역할 정의, 조정 등 조합적 탐색 공간을 다루고 하위 LLM과 공진화까지 시켜야 해서 비용이 큼. 그래서 IP라는 것임.

![지식 증류 vs 하네스 증류](/images/2026-08-03-agent-harness-distillation-inference-time-harness-extraction/fig-1-p3.png)

2. 기존 IP 유출 연구와 다른 지점. MASLeak 같은 연구는 정적으로 정의된 통신 토폴로지 복원이었음. 근데 AMAS의 하네스는 각 작업 실행 동안 잠깐 존재했다가 사라지는 일시적 상태임. 게다가 실제 배포에선 중간 출력이 차단됨. Codex MultiAgentV2는 위임 정보를 암호문으로 기록함. AHD는 이보다 더 엄격한 순수 블랙박스, 최종 응답만 관찰 가능한 설정을 다룸.

3. 위협 모델. 공격자는 백본 LLM의 아키텍처와 파라미터를 알고(같은 모델에 접근 가능), 일반 사용자 권한으로 질의만 보낼 수 있음. 하네스와 내부 로그엔 접근 불가. 질문은 "모델은 알고 하네스는 모르는 상태에서 응답 패턴만으로 하네스를 역추론할 수 있는가"임.

4. 사전 증류 단계. 원래 작업에 주입 프로브를 결합해 확장 질의를 만듦. Prefix는 컨텍스트 신뢰성에 불확실성을 심어 보조 하위 에이전트 구성과 도구 호출을 유도해서 평소 안 보이던 하네스 구성 요소를 드러냄. Suffix는 작업 완료 후 실행 궤적을 회고 분석해 기저 워크플로를 요약하게 만듦.

5. 노이즈 제거 2단계가 품질의 핵심임. 첫째, 작업 내 다수결 투표로 n번 독립 실행 중 일관되게 재현된 정보만 남겨 불안정한 자기 보고를 제거함. 둘째, 작업 간 빈도 집계로 서로 다른 작업에서 일관되게 등장하는 구조만 남겨 작업 특정 아티팩트를 걸러냄. 그 결과로 추정 하네스 템플릿을 실행 가능한 다중 에이전트 시스템으로 인스턴스화함.

6. 사후 증류는 Loop Harness Alignment임. 공격자 자신의 에이전트에 작업을 실행하고 추론 시간 하네스를 관찰하고, 코딩 에이전트가 관찰된 하네스와 복원된 타겟 하네스를 비교해서 수정을 제안하고, 검증 세트 성능이 유지되면 수락함. 거부된 수정은 누적돼서 같은 실수를 반복하지 않게 함. 고정 예산 소진이나 수렴까지 돌림.

7. 형식화도 깔끔함. 하네스 추출을 학습 이론의 역문제로 정의함. 관찰 가능한 상호작용에서 숨겨진 실행 메커니즘을 복구하는 것. 그리고 행위적 구별 불가능성 개념으로 블랙박스 관찰은 행위적 동치류까지만 식별 가능하다는 한계를 명시함. 목표는 정확한 복원이 아니라 행위적으로 동등한 하네스임.

8. 실험. 대상은 Claude Code와 Hermes, 둘 다 GPT-5.4 백본. 추출된 하네스를 Qwen3.6-Flash, Qwen3-80B, DeepSeek-V3, GPT-5.4에 전이해 AIME2025, GSM-Level6, GAIA, MMLU-Pro CS로 평가함.

![사전 증류 전이 정확도](/images/2026-08-03-agent-harness-distillation-inference-time-harness-extraction/table-1-p8.png)

9. 핵심 발견 둘. 첫째, 약한 모델일수록 전이 효과가 큼. Qwen3.6-Flash와 DeepSeek-V3에서 가장 큰 향상, GPT-5.4는 이미 강해서 차이가 거의 없었음. 하네스는 모델 추론 능력이 병목일 때 가장 큰 가치를 더한다는 뜻임. 둘째, 4개 공격 지표에서 일관되게 강함. 추출된 하네스가 원래 구조를 실제로 포착했다는 것임.

10. 4개 지표 체계도 평가 설계로 벤치마킹할 만함. Clean Visibility는 정상 응답에서 하네스가 새는 정도, Injected Fidelity는 주입 후 추출 정확도, Clean Transfer는 추출 결과의 일반화, Probe Perturbation은 공격의 은밀성을 측정함. "정보가 유출되는가"가 아니라 "유출된 정보가 활용 가능한가"를 구조적으로 평가하는 프레임임.

![방어 효과](/images/2026-08-03-agent-harness-distillation-inference-time-harness-extraction/fig-3-p8-5.png)

11. 방어는 기만 기반임. 추출 시도를 감지하면 그럴듯하지만 거짓된 하네스 정보를 반환함. 핵심은 거짓 정보가 상호작용마다 일관성이 없어서 공격자가 집계 못 하게 하는 것. 그리고 사후 증류의 정렬 루프에 충돌하는 목표를 주입해서 증류가 서로 다른 방향으로 수렴하려 하게 만듦. 시스템 컨텍스트에 영구 명령으로 삽입되는 단일 라운드 방어라 개선 여지가 큼.

12. 실무 채점. 자체 하네스를 운영하는 조직이 묻는 질문 세 개임. 첫째, 내 에이전트가 프로브 질문에 실행 구조를 자기 보고하고 있진 않은가. 둘째, 하위 에이전트 위임 정보가 로그에 평문으로 남아 있진 않은가. 셋째, 응답 패턴에서 시스템 수준 구조가 여러 작업에서 반복 노출되고 있진 않은가. 이 세 지점이 AHD가 실제로 활용하는 표면임.

13. 방어를 설계한다면 벤치마크할 원칙. 여러 질의에 걸친 구조 정보의 집계 가능성을 끊는 것. 일관성 없는 은닉보다 일관성 없는 기만이, 회고 분석 유도 프롬프트에 대한 감지가 출발점임.

14. 더 근본적인 리스크도 지적함. 자신의 실행 궤적에 접근할 수 있는 에이전트 자신이 공격자가 되는 경우임. 감시 경계 밖에서 기능적으로 동등한 섀도 복제본을 만들 수 있고 이는 자기 복제 우려로 이어짐. 하네스 멤버십 추론 공격 같은 프라이버시 확장도 새 공격 벡터임.

15. 그리고 트레이드오프. 하네스를 완전히 숨기면 감사가 불가능해지고 전부 공개하면 IP 보호가 무의미해짐. 논문은 실행 궤적 공개 대신 미리 정의된 보안 속성에 대한 암호학적 검증으로 전환하는 걸 대안으로 제시함. 하네스가 IP라는 건 하네스를 이해하는 사람이 곧 시스템을 이해하는 사람이라는 뜻이기도 함.
