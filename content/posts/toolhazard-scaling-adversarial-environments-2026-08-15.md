LLM 에이전트를 노리는 간접 프롬프트 인젝션 테스트 환경을 사람이 손으로 짜지 않고 합성 파이프라인으로 계속 늘리는 [프레임워크](https://arxiv.org/abs/2608.11878)가 나옴. 기존 보안 벤치마크는 AgentDojo(간접 프롭프트 인젝션 등 에이전트 공격을 평가하는 공개 벤치마크) 도메인 4개, ASB(에이전트 보안 시나리오 벤치마크) 10개 전부 수작업 환경인데다 주입 위치도 미리 정해둬서 새 공격 표면을 시험하려면 또 손으로 고쳐야 했음. 확장이 안 되는 이유가 제작 비용이었는데 ToolHazard는 환경 코드, 공격 지점, 검증 함수까지 자동 생성으로 바꿈. 환경 1개 합성 비용이 $0.59임.

1. 구조는 세 모듈임. 환경 시뮬레이터가 시드 태스크에서 상태 공간과 제약 규칙을 추론해서 OOP 실행 코드를 만들고 테스팅·체킹 에이전트 이중 검수를 통과한 환경만 남김. 공격자 에이전트가 주입 지점을 찾는데 여기가 기존 red-teaming과 다름. 미리 정해둔 위치에 페이로드를 넣는 게 아니라 쓰기 가능한 텍스트 속성을 식별하고 연산별 읽기/쓰기 의존성 그래프를 분석해서 읽기와 쓰기 경로가 둘 다 있는 속성만 유효 공격점으로 채택함. 어디가 뚫리는지를 환경 코드에서 직접 찾는 것. 사용자 시뮬레이터가 장기 태스크를 만듦. 태스크 완수 판정은 LLM 심판 없이 최종 환경 상태에 체크 함수를 실행하는 결정론 방식이고 사람 판정과 일치율 95% 이상임.

![프레임워크 개요](/images/toolhazard-scaling-adversarial-environments-2026-08-15/overview-framework.png)

2. 규모. 환경 28개, 태스크 87개, 도구 512개에 평균 실행 길이 15.56스텝, 태스크당 후보 도구 18.75개. 기존 보안 벤치마크(AgentDojo 4.19스텝, ASB 2.96스텝)보다 워크플로 복잡도가 한 단계 높고 환경당 상태 속성 밀도도 AgentDojo와 비슷해서 합성 환경이 성기지 않다는 검증도 됐다는 것. 공격은 6가지 래퍼 전략으로 인스턴스화되는데 고전적인 "이전 지시 무시"류부터 사용자 메시지 위장, 가짜 대화 턴, 그리고 Decision Hijacking, Tool Selection, Reasoning Criteria 같은 새 전략까지 있음.

![벤치마크 통계](/images/toolhazard-scaling-adversarial-environments-2026-08-15/bench-stats.png)

3. 결과가 무서움. GPT-5가 전략 4개에서 공격 성공률 40%를 넘김. Tool Selection 전략엔 59.14%. Gemini-3.1-Pro도 3개가 30% 초과. 고전적인 Basic Combined에는 다들 강한데 새 전략 앞에서는 일관되게 무너짐. 그리고 흥미로운 역상관이 하나 있음. 정상 태스크 수행률이 최고인 DeepSeek-V3.2가 공격에는 가장 취약함. 환경 지시를 충실히 따르는 능력 자체가 악성 주입도 충실히 따르는 결과로 이어진다는 논문의 해석인데, 지시 추종과 인젝션 내성이 같은 축이라는 게 구조적 문제라는 뜻임.

![여섯 가지 인젝션 전략](/images/toolhazard-scaling-adversarial-environments-2026-08-15/six-strategies.png)

4. 실무적으로 제일 쓸모 있는 발견 두 개. 첫째, 주입 타이밍과 배치. 같은 페이로드도 실행 초반에 읽히는 주입점일수록, 도구 응답의 마지막 필드에 들어갈수록 성공률이 오름. 위치 편향 때문인데 방어 설계할 때 위치를 고려해야 한다는 근거가 됨. 둘째, 출력 포맷. 같은 환경에서 도구 출력만 자유 텍스트와 JSON/YAML로 바꿔 비교했더니 자유 텍스트 쪽이 크게 높았음. 구조화 포맷의 구문 경계가 부차적 격리 역할을 한다는 것. 도구 출력을 구조화하고 엄격 파싱을 붙이는 것만으로 실질 방어가 된다는 게 이 논문이 주는 제일 싼 처방임.

![주입 타이밍과 배치](/images/toolhazard-scaling-adversarial-environments-2026-08-15/timing-placement.png)

5. 인젝션은 안전 문제만 만드는 게 아니라는 것도 짚힘. 공격받는 환경에서는 정상 태스크 수행률도 같이 떨어져서 GPT-4.1은 Multi-turn 공격에 BR(정상 태스크 수행률)이 절반까지 하락함. 안전 위반과 능력 저하를 같이 봐야 한다는 것.

6. 정렬 데이터 합성까지 이어짐. 보상이 잘 설계돼 있는데 트레이젝토리 단위로 정상 태스크 완수에 보상, 주입 지시 이행에 벌점을 주는 구조임. 거절만 하면 태스크 실패로 점수가 깎이니 최대 보상을 받으려면 공격을 무시하고 과제를 끝내야 함. 과잉 거부 없이 방어를 학습시키는 설계. Qwen3-8B에 GRPO(같은 태스크의 여러 시도를 묶어 상대 성적으로 학습 신호를 만드는 RL 알고리즘)를 돌려서 공격 성공률(ASR) 36.10%에서 18.06%로 절반 가까이 줄면서 BR도 오르고, 환경 분포가 다른 AgentDojo에서도 ASR이 개선돼서 벤치마크 암기가 아님. 전략 3개로만 학습하고 나머지 3개로 평가해도 근접 성적이라 래퍼별 암기를 넘어 견고성이 이전됐다는 근거도 있음.

![정렬 결과](/images/toolhazard-scaling-adversarial-environments-2026-08-15/align-results.png)

7. 비용 구조가 인상적임. 환경 1개 $0.59 중 $0.46이 자동 검수. 품질 관리가 파이프라인에서 가장 비싼 단계라는 것. 앞서 정리한 NexForge, RST와 같은 결론인데 합성 데이터의 비용은 생성이 아니라 검증에 있다는 것이 반복 확인됨.

8. 한계는 명확함. 합성 환경과 실제 엔터프라이즈 시스템 사이 갭이 있어서 프로덕션 위험 추정치로는 못 쓰고 재현 가능한 스트레스 테스트 프레임으로 봐야 함. 공격 전략 6종은 고정이고 정렬 실험은 8B까지. 내가 가져갈 방어 원칙 네 개. 실행 초반 스텝의 입력 검증을 더 세게, 도구 출력은 구조화 + 엄격 파싱, 관찰 끝 필드가 위험 위치라는 인지, 정렬·게이트 설계는 "과제 완수 + 주입 무시" 조합으로 하되 거절 자체에 점수를 주지 말 것.
