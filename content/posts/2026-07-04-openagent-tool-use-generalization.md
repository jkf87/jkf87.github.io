도구 사용 에이전트를 파인튜닝해서 벤치마크 90%를 찍었다. 근데 실제 배포 환경에서 API 하나가 바뀌면 성능이 무너진다. ICML 2026에 나온 OpenAgent 연구가 이 현상을 정식화하고 원인을 진단함. MCP(모델이 외부 도구·데이터 소스에 표준 규격으로 접속하게 하는 프로토콜) 붙이고 에이전트 돌리는 사람이라면 그냥 지나칠 수 없는 내용임.

1. 문제의 출발은 "닫힌 세계의 환상"임. SFT(지도 미세조정, 정답 행동 예시를 그대로 흉내 내도록 훈련하는 방식)와 RL(보상 신호를 최대화하는 행동을 시행착오로 찾게 하는 훈련 방식)로 훈련된 오픈소스 에이전트들이 기존 벤치마크에서 90% 이상을 기록함. 근데 그 벤치마크는 도구 스키마가 고정되고 응답 포맷이 깨끗한 세계임. 실제 환경에서는 API가 폐기되고, 스키마가 진화하고, 사용자 지시는 모호함. 연구진은 이 간극을 쿼리, 도구, 관측, 도메인 네 차원의 분포 이동으로 정의함. 핵심은 이동이 누적된다는 것. 어느 스텝에서 궤도가 틀리면 이후 모든 의사결정이 오염됨.

2. 평가는 깊이에 따라 4단계로 나눴음. 티어1은 도구 이름·파라미터 라벨 같은 표면 변화, 티어2는 도구 동작의 의미 변경·신규 도구 도입, 티어3은 도구 간 의존성 역전, 티어4는 치명적 오류에서의 회복력임. 나는 이 티어 구조 자체가 실무 체크리스트로 쓸만하다고 봄. 자사 에이전트 배포 전에 "도구 이름 바꿔봤나, 오류 응답 넣어봤나"를 티어 순서대로 검사하면 됨.

![Figure 3: 4단계 평가 과제 구조도 — Perception, Interaction, Reasoning, Internalization](/images/2026-07-04-openagent-tool-use-generalization/fig-p7.png)

3. 결과가 충격적임. SFT 에이전트는 학습할수록 더 취약해짐. SFT-200 단계에서 티어1 정확도가 67.7%p 하락. 트라젝토리 과적합이라 부르는 증상임. 학습 데이터의 깨끗한 궤적에만 최적화되어 도구 이름만 바뀌어도 즉시 무너짐. 논문은 이걸 symbolic anchoring이라 이름 붙였음. "클린 데이터로 더 오래 훈련한다"는 통념이 도구 에이전트에서는 정반대 결과를 낳는 셈임.

4. RL 에이전트는 사정이 다름. 의미적 이해는 SFT보다 나음. 근데 목표 달성 보상에 최적화되다 보니 도구가 반환하는 오류 신호를 제대로 처리하지 못함. boundary blindness라는 증상임. 성공 보상만 세면 에이전트가 실패 경로를 배우지 않는다는 얘기임. RL로 에이전트 훈련하는 팀이라면 보상 설계에 오류 회복 경로를 명시적으로 넣어야 한다는 지적으로 읽힘.

5. 해법이 의외로 단순함. PAFT(Perturbation-Augmented Fine-Tuning). SFT 훈련 데이터에 제어된 섭동을 주입하는 것. 관측에 에러·None을 끼워 넣고(EFP), 도구 이름·파라미터 라벨을 바꾸고(SBP), 도구 설명을 변형함(SRP). 아키텍처 변경이 전혀 없음. 데이터에 노이즈를 섞는 것만으로 티어1이 -67.7에서 +28.6로 반전됐고, 치명적 오류 회복률은 0.3%에서 99.3%로 감.

![Figure 8: PAFT 적용 후 성능 변화 — 섭동 주입만으로 회복률이 극적으로 개선된다](/images/2026-07-04-openagent-tool-use-generalization/fig-p8.png)

6. 섭동 비율에도 sweet spot이 있음. α=0.3일 때 회복률 99.6%로 최고. 0.4까지 올리면 오히려 학습이 방해됨. 과유불급이 숫자로 나타나는 부분임. 그리고 과적합이 진행되기 전 초기 모델일수록 PAFT 효과가 큼. 개입 타이밍이 이르면 이를수록 좋다는 뜻임.

7. 내 실무 결론은 세 가지임. 첫째, 정적 벤치마크 점수를 믿고 배포 결정을 하지 말 것. 둘째, 도구 사용 파인튜닝을 한다면 클린 트레이젝토리만 쓰지 말고 일부러 스키마를 뒤틀고 오류를 심은 데이터를 섞을 것. 이건 구현 비용이 거의 없음. 셋째, 평가는 고정 도구셋이 아니라 살아있는 환경에서 할 것. 이 논문의 제어된 섭동 프레임이 그 평가 설계의 틀을 줌.

근데 한계도 분명함. PAFT가 완전 복구는 아님. 후기 단계 티어3에서 여전히 음수이고, RL용 섭동 전략은 별도로 없음. 데이터 증강은 만능이 아니라는 경계선임.
