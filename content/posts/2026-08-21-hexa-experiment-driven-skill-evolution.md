HExA(Hierarchical Experimentalist Agents, arXiv 2606.29315)는 가중치 업데이트 없이 에이전트가 직접 실험을 설계·수행하고 그 결과를 자연어 스킬 뱅크로 증류해 재사용하는 프레임워크임. Claude Sonnet 4.6 기준 catapult 난이도 성공률 2%→67.3±9.3%, 에피소드당 평균 반복 22.9(ReAct, 생각과 행동을 번갈아 출력하며 도구를 쓰는 기본 에이전트 프롬프트 방식)→14.4로 줄었음.

1. 문제의 출발. LLM이 물리 법칙을 파라미터에 알고 있다고 새 물리 퍼즐에서 올바른 배치를 바로 찾진 못함. 도구 없이 한 번에 답하는 Direct 조건에서 Claude Sonnet 4.6가 8개 레벨 중 가장 어려운 catapult에서 2% 성공에 그침. 아는 것과 쓸 수 있는 것은 다르다는 것임.

2. 접근은 actor-evolver-retriever 루프임. actor가 시뮬레이터를 도구로 쓰며 개입·실험을 수행함. evolver가 같은 모델의 다른 프롬프트로 궤적 배치를 읽고 고보상 궤적과 저보상 궤적을 대조해 자연어 스킬과 실수 기록을 뽑음. retriever가 스킬 뱅크에서 상위 M개 스킬과 상위 N개 실수 기록을 골라 다음 에피소드 시스템 프롬프트 앞에 붙임.

3. 전부 프롬프트 컨텍스트로 동작함. 파인튜닝도, 오라클 정답도, 오프라인 데이터도 없음. 폐쇄형 API 모델에도 그대로 적용 가능하다는 게 이 프레임워크의 실용적 지점임.

![HExA 프레임워크](/images/2026-08-21-hexa-experiment-driven-skill-evolution/fig-1-p2.png)

4. 스킬 뱅크 구조가 잘 설계됨. 스킬은 제목, 원리 2~3문장, 적용 조건, 예시, 유래 seed, 보상 점수의 구조화된 레코드임. 실수 기록은 무엇이 틀렸는지, 어떤 잘못된 인과 믿음 때문인지, 수정 전략의 세 필드임. 실패 궤적 안의 부분적 정답(메커니즘은 맞았는데 실행이 틀린 경우)도 낮은 점수로 살아남음.

5. evolver의 증류는 두 패스임. 패스 1은 성공 vs 실패를 대조해 전략 스킬 4~6개를 뽑고 패스 2는 실패 궤적만으로 반복 실수 패턴과 부분 스킬을 추출함. 성공 궤적만으론 어느 중간 단계가 필수였는지 알 수 없어서 실패 분석이 독립된 학습 신호가 된다는 게 저자들의 논점임.

![루프 구조](/images/2026-08-21-hexa-experiment-driven-skill-evolution/fig-2-p4.png)

6. 평가 환경 Interphyre는 PHYRE 2D 절차적 물리 환경 위에 tool-calling API를 얹은 벤치마크임. 에이전트가 장면 조회, 개입 배치, 시뮬레이션 실행 API로 가설을 검증함. 50 seed 성공률과 seed당 평균 반복 횟수로 측정함.

7. 결과. catapult에서 Direct 2.0%, ReAct 8.0%, Reflexion(실패 후 언어로 성찰을 남겨 다음 시도 프롬프트에 반영하는 방식) 21.3%에 비해 HExA(Off2On Evolving) 67.3±9.3%. 성공률이 오르는 동시에 반복 횟수도 약 37% 줄어듦. 누적 스킬이 탐색 비용을 상각해주는 것임. Reflexion의 언어적 성찰이 21.3%에 머무는 것과 비교하면 경험을 명시적·재사용 가능한 뱅크로 바꾸는 게 성찰만으로는 부족하다는 뜻임.

![보상 유도 스킬 축적 효과](/images/2026-08-21-hexa-experiment-driven-skill-evolution/fig-5-p10.png)

8. 오픈 웨이트에서도 이득임. Qwen-2.5-7B는 down_to_earth 62%→72%, two_body_problem 18%→34%. GPT-OSS-120B는 catapult에서 ReAct 0%→HExA 54%임. 프론티어 모델의 사전 지식만으로 설명되지 않는다는 근거임.

9. 어블레이션에서 걸리는 지점. Off2On Evolving 76%, Online 시작 44%, Iterative Replacement 56%(catapult 기준). 기존 뱅크를 버리고 매번 새로 증류하면 이전 스킬이 사라져 과적합이 커짐. 웜스타트 + 점진 진화가 유리하다는 결론임.

10. 보상 라벨을 빼면 catapult 67.3%→50.7%로 떨어짐. 다만 보상이 아예 없어도 evolver의 사전 지식만으로 50% 선은 지킴. 환경 보상이 없는 도메인에도 적용 여지가 있다는 뜻임.

11. GRPO(가중치를 미분으로 직접 갱신하는 대표적인 RL 파인튜닝 알고리즘)와의 비교가 정직함. 동일 seed 예산의 저데이터 영역에선 HExA가 앞서지만 학습을 충분히 돌리면 GRPO가 역전함(down_to_earth 100% 수렴). 그래서 "새 도메인 초기 진전 확보용 in-context 부트스트랩 + 이후 파라미터 RL" 하이브리드를 후속 과제로 제시함. 이 순서가 실무 로드맵이기도 함.

12. 스킬 이전 결과도 강력함. catapult를 한 번도 안 푼 상태에서 쉬운 레벨에서 진화한 스킬 뱅크를 재접지해 주입하는 zero-shot 이전만으로 44%. ReAct 8%, Reflexion 16%와 비교됨. 이전 프롬프트에 "대상 좌표를 지어내지 말 것, 원본 스킬 ID로 소급 가능해야 할 것" 제약을 붙여서 좌표 암기를 차단하고 메커니즘 추상화만 옮겨가게 설계했다는 게 핵심임.

![이전 사례](/images/2026-08-21-hexa-experiment-driven-skill-evolution/fig-4-p10.png)

13. 실제 풀리는 과정이 이 논문의 결정적 장면임. seed 45에서 HExA는 뱅크 스킬들을 조합함. 낙하 높이를 올리고 정준 위치를 첫 시도로 쓰고, 천장 충돌로 실패하자 폴백 x 값을 적용해 다음 시뮬레이션에서 성공함. 새 추론이 거의 없음. 뱅크에 조합 가능한 답이 이미 들어 있었기 때문임.

14. 실무 채점. 이 논문의 실용 가치는 "실험 → 스킬 뱅크 → 검색 주입" 루프가 모델 교체 없이 폐쇄형 API 위에서도 돈다는 것임. CLAUDE.md 같은 프로젝트 메모나 에이전트 스킬 파일을 매번 사람이 손으로 쓰는 대신 evolver가 궤적에서 자동 증류하는 구성으로 바꿀 수 있다는 근거가 됨.

15. 한계도 분명함. evolver의 추론 능력이 스킬 품질의 상한이 되고, 이진 성공+효율 보상이라 간결한 성공 기준 없는 도메인으로 바로 안 가고, evolver 호출 오버헤드가 매 라운드 추가됨. 물리 시뮬레이터라는 깔끔한 성공 기준이 있어서 가능한 결과라는 점은 도메인 옮길 때 직접 검증해야 함.
