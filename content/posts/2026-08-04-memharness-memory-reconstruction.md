에이전트에 경험 메모리를 넣으면 성능이 오를 거라 생각하는데 실제로는 반대가 될 때가 많음. [MemHarness](https://arxiv.org/abs/2607.25906)가 이유를 밝힘. 과거 궤적을 그대로 복사해 끼워넣으면 환경이 다를 때 잘못된 행동을 유도하기 때문. 해법은 검색과 실행 사이에 "이 경험이 지금 상황에 맞는지 비교하고 고쳐 쓰는" 재구성 단계를 넣는 것. 이걸 GRPO(같은 문제의 여러 롤아웃을 뽑아 그룹 평균 대비 성과로 학습하는 강화학습 알고리즘)로 end-to-end 학습시켰더니 7B 모델이 GPT-4o를 넘어섬. 나도 메모리 기반 에이전트를 운영 중이라 그대로 적용할 지점을 정리함.

1. 문제부터. ALFWorld(텍스트 기반으로 물건 옮기기·가열 같은 가사 과제를 시뮬레이션하는 에이전트 벤치마크)에서 현재 과제가 "컵을 사이드테이블에 놓아라"인데 메모리에 "신용카드를 커피테이블에 놓았다"가 있으면 에이전트가 혼란에 빠짐. 검색 관점에서는 관련된 것 같은데 실행 맥락이 다르면 마이너스가 되는 것. 논문은 이걸 verbatim replay의 한계라고 부름. 사람은 과거 경험을 떠올린 뒤 지금 상황과 비교해서 수정해서 쓰는데, 기존 에이전트는 비교와 수정을 안 했음.

![기존 방식과 재구성 방식 비교](/images/2026-08-04-memharness-memory-reconstruction/fig-1-p2.png)

2. 구조는 세 단계임. 검색에서 현재 관찰로 메모리 뱅크를 쿼리하고, 재구성에서 가져온 경험이 현재 상황에 맞는지 비교해서 맞지 않는 부분을 고쳐 씀. 쓸모없으면 빈 값을 반환함. 행동에서 재구성된 가이드를 보고 실행 가능한 행동을 생성함. 세 단계 전부를 하나의 7B 정책 모델이 처리함. 재구성 단계를 위한 정답 데이터가 없어서 태스크 보상(성공 10, 실패 0)만으로 GRPO 학습을 시킴. 별도 라벨 없이 재구성 능력이 자연스럽게 나타난다는 게 설계의 미덕임.

3. 숫자가 이 논문의 전부를 말해줌. ALFWorld와 WebShop(이커머스 쇼핑몰을 모방해 원하는 상품을 검색·구매하게 하는 웹 과제 벤치마크)에서 순수 GRPO가 76.4%, 70.6인데 Mem0(오픈소스 에이전트 메모리 시스템)를 그냥 끼워넣은 GRPO는 69.0%, 65.1로 오히려 떨어짐. 메모리를 무비판적으로 넣는 게 7.4%의 해가 된다는 것. MemHarness는 재구성 단계 하나로 85.2%, 80.1을 냄. GRPO 대비 +8.8%, +9.5%. 7B 모델이 GPT-4o few-shot을 ALFWorld에서 +22.9%, WebShop에서 +20.9% 앞섬.

![성적표](/images/2026-08-04-memharness-memory-reconstruction/fig-2-p3.png)

4. 제일 아픈 숫자는 OOD(학습 분포 밖, 즉 학습 때 못 본 새로운 배치와 객체 위치) 설정임. 학습에 없던 방 배치와 객체 위치에서 재구성 없이 메모리를 넣으면 82.4%로 메모리를 아예 안 쓰는 순수 정책(83.0%)보다 못함. 근데 재구성이 있으면 85.9%로 올라감. 즉 메모리는 재구성이 동반될 때만 자산이고, 없으면 부채라는 것. 내 메모리 시스템에도 그대로 적용되는 문장임. 검색해서 넣는 것으로 끝나는 메모리 주입은 새 환경에서 독이 될 수 있음.

5. 학습이 진행되며 메모리 사용 방식이 진화하는 것도 관찰됨. ALFWorld에서는 검색 횟수가 에피소드당 2-3회로 수렴함. 필요할 때만 찾는 학습이 된 것. WebShop에서는 검색은 계속 자주 하되 거절 비율이 일정하게 유지됨. 환경 특성에 따라 다른 메모리 전략을 스스로 익힘. 그리고 수용된 재구성이 포함된 궤적의 성공률이 거절된 궤적보다 일관되게 높음. 거절이 아니라 그냥 다 수용하는 회로였다면 이 차이가 안 나야 하니, 에이전트가 실제로 의미 있는 판단을 하고 있다는 증거임.

![학습에 따른 검색/거절 비율 변화](/images/2026-08-04-memharness-memory-reconstruction/fig-3-p8.png)

6. 재구성이 실제로 비교를 하고 있다는 검증도 깔끔함. 재구성 입력에서 소스 관찰을 빼면 성적이 떨어지고(85.2→80.0), 무작위 관찰로 바꾸면 거절률이 ALFWorld에서 8.7%→13.3%, WebShop에서 56.0%→63.3%로 오름. 필드의 유무가 아니라 실제 내용을 현재 상태와 대조하고 있다는 뜻임.

7. 실무 번역은 어렵지 않음. 내 에이전트의 메모리 주입 로직에 "이 기억이 지금 작업과 같은 맥락인가"를 판단하는 단계를 하나 넣는 것. 맥락이 다르면 기억을 버리거나 고쳐서 넣는 것. 사람이 수동으로 하던 일을 프롬프트로 정형화하는 것만으로 재구성 없는 verbatim 리플레이의 해를 줄일 수 있음. 그리고 "재구성 학습을 하면 메모리 없는 추론에서도 기본 능력이 오른다(83.0 vs 76.4)"는 결과도 눈여겨볼 만함. 좋은 메모리 습관이 모델 자체의 추론까지 끌어올린다는 것.

8. 한 줄 요약. 메모리의 가치는 보관이 아니라 검색과 실행 사이의 비교·수정에서 나옴. 과거를 복사하지 말고 다시 쓰게 하라는 것.
