도구 사용 능력을 post-training(SFT·강화학습 같이 사전학습 이후에 가중치를 조정하는 단계)에만 맡기지 말고 mid-training(사전학습과 post-training 사이 중간 학습 단계) 단계에서 전용 데이터로 심어야 한다는 주장이 나옴. Snowflake의 [MidTool](https://arxiv.org/abs/2608.20314). 소형 에이전트 모델을 직접 튜닝하는 사람에게 데이터 설계 철학이 참고가 돼서 정리함.

1. 배경. 도구 사용 능력은 지금까지 거의 전부 SFT와 RL로 만들어졌음. 근데 이 방식은 모델이 도구 인식, 스키마 기반 인자 구성, 명확화 요청, 멀티스텝 실행을 좁은 감독 신호만으로 한 번에 배워야 하는 구조적 부담이 있음.

2. 연구팀은 이걸 두 결핍으로 나눔. Grounding은 문서·PDF·코드 같은 지저분한 실자료에서 도구 경계와 필수 인자를 추론하는 능력. Execution은 여러 턴에 걸쳐 계획하고 누락 정보를 되묻고 순서를 지켜 호출하는 능력. MidTool의 두 합성 브랜치가 각각를 겨냥함.

3. 데이터 구성이 재미있음. 20.3B 토큰 11.22M 샘플 중 Web 42%, Code 26%, PDF 23%, 네이티브 트라젝토리 9%. "깨끗한 데모 수집"이 아니라 지저분한 실자료(API 레퍼런스, 매뉴얼, CLI 문서)에서 출발해서 강한 교사 모델로 QA와 트라젝토리를 합성하고 턴 순서·스키마·인자·응답 일관성 검증을 통과한 것만 남김.

4. 오염 관리도 두 겹임. 수집 단계에서 평가 벤치마크 관련 저장소를 블랙리스트로 제외하고, 완성 믹스를 DeCon(벤치마크 오염 여부를 검사하는 도구)으로 재검사. 리키지 증거 없다고 보고함. 이 절차 자체가 내부 데이터셋 구축의 체크리스트가 됨.

5. 숫자. Qwen3-4B에 SFT만 붙였을 때 BFCLv3 Overall 39.73% → 50.25%(RL 추가 시 54.18%). 멀티턴 평균은 15.50% → 26.63%로 10점 이상 상승. τ²-Bench(통신사 등 고객 응대 시뮬레이션으로 정책 준수·도구 사용을 채점하는 벤치마크) Pass@1 8.54% → 12.23%(RL 포함 19.96%). MCP-Universe(MCP 도구를 실제로 연결해 쓰는 능력을 측정하는 벤치마크) Score 13.20 → 18.66. 8B에서도 같은 패턴.

6. 절제 실험의 교훈. 문맥 증강만 남기면 BFCL +4.9, 네이티브 트라젝토리만 남기면 +7.9. 완성 믹스만 8개 지표 전부에서 개선. grounding 지도와 execution 지도는 상호 보완적이라는 것 — 한쪽만 훈련하면 안 됨.

7. 일반 mid-training 데이터(Dolmino-20BT) 비교도 시사적임. BFCL 일부는 오르지만 τ²-Bench와 MCP-Universe 전이는 약함. 범용 명령이행 데이터는 심플한 함수 콜엔 도움되지만 에이전트 설정으로는 전이가 안 된다는 것. "일반적으로 좋은 데이터"가 아니라 "과제에 맞는 데이터"여야 함.

8. 학습 동역학의 디테일이 좋음. RL 훈련 보상은 나중에 서로 비슷해지는데 벤치마크 격차는 그대로 남음. 학습 환경 적응만으로 최종 품질이 정해지지 않고 mid-training의 진짜 가치는 범용성 쪽이라는 것.

9. 능력 경계도 솔직함. MCP-Universe의 웹 검색 서브셋은 0.00에 머묾. 브라우저 자동화·금융·위치는 개선되니 도구 전이 자체는 잘 된 것이고, 긴 호라이즌 탐색·반복 정제가 필요한 deep-search류 행동은 별도 감독이 필요하다는 것. 일반 도구 사용과 전문 에이전시를 가르는 경계임.

10. 여기서 문제제기. 훈련 안 하는 사람에게 뭐가 남나. 남는 건 데이터 설계 철학임 — 도구 문서를 크롤링해두고 그걸로 QA와 호출 트라젝토리를 합성해 검증 통과본만 쌓는 파이프라인. 이건 프롬프트 기반 파인튜닝 데이터셋 준비에도 그대로 적용됨. 내 도구 문서에서 인자 누락 상황 연습 케이스를 만들어두는 식.

11. 약점도 명확함. 두 합성 브랜치 전부 GPT-5, Qwen3-235B 같은 강한 교사에 의존함. 논문도 "오픈웨이트 에이전트가 자기 도구 사용 학습 데이터를 합성하는 시점"을 에이전트 성숙도의 척도로 보자고 제안. 교사 비용이 숨은 진입장벽임.

12. 데이터와 모델이 전부 공개돼 있어서([HuggingFace](https://hf.co/collections/MidTool/midtool-release)) 미드트레이닝 실험이 중소 팀도 접근 가능한 영역이 됐다는 게 실무적으로 제일 큰 변화. 커리큘럼 관점에서 mid-training과 post-training을 함께 설계하는 게 다음 질문임.

13. 결론. 도구 사용 능력의 상당 부분이 post-training 이전에 결정됨. 지저분한 실자료 + 실행 검증 합성이라는 데이터 철학이 핵심. 근데 deep-search류 장거리 탐색은 이걸로 안 된다는 경계 — 범용 도구 사용과 전문 에이전시를 분리해서 투자해야 한다는 결론임.
