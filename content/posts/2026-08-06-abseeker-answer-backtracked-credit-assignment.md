검색 에이전트 RL의 고질적 낭비가 하나 있음. 최종 답의 맞고 틀림만으로 전체 궤적에 같은 점수를 준다는 것. 성공한 궤적에도 잘못된 스텝이 섞여 있고 실패한 궤적에도 제대로 된 스텝이 있는데 둘을 구분 못 함. ABSeeker는 이 문제를 정답에서 거꾸로 추적하는 크레딧 할당으로 품. 결과가 인상적. 4B가 30B급 에이전트를 넘고 컨텍스트 관리를 더하자 BrowseComp(정답을 찾으려면 여러 차례의 웹 검색이 필요한 어려운 탐색 질문 벤치마크) 55.3%까지 감.

1. 핵심 아이디어가 단순함. 정답을 알고 있으면 정답에서 필요한 단서를 거꾸로 복원함. LLM이 ReAct 루프(생각-행동-관찰을 번갈아 기록하며 진행하는 에이전트 실행 방식)를 돌며 웹 검색으로 단서를 실제 검증함. 그다음 궤적의 각 스텝을 복원된 단서 집합과 비교해 채점함. 올바른 단서를 발견하거나 검증하면 +0.8, 잘못된 후보를 올바르게 배제하면 +0.4, 올바른 단서를 잘못 배제하면 -0.8, 정답 제출 +1.0, 오답 제출 -1.0. 기본 1.0에서 누적해 0~2.0으로 클리핑함. [답 → 단서 복원 → 스텝별 채점]이 전부임.

![](/images/2026-08-06-abseeker-answer-backtracked-credit-assignment/fig-2-p4.png)

2. 채점 예시가 직관적임. 네 제약이 있는 질문의 정답이 CeraVe라면 복원되는 단서는 Ceramides(성분), L'Oréal(인수사), Schueller(창립자) 등 여섯 개. 22번째 스텝이 Ceramides를 발견해 연결하면 1.8점. 35번째 스텝이 인수사와 창립자를 동시 검증하면 2.0점. 56번째 스텝이 쌓인 증거를 버리고 잘못된 후보로 회귀하면 0.2점. 궤적 전체가 실패로 끝나도 22번과 35번 스텝은 보상을 받는 것. 데이터 낭비를 줄이는 구조임.

3. 이 점수를 두 군데에 씀. ABC-SFT는 스텝 점수로 SFT(정답 예시로 모델을 미세조정하는 지도 학습) 손실 가중치를 조정함. 8.5K 궤적 중 오답 궤적 3.0K도 버리지 않고 씀. ABC-GRPO는 스텝 점수를 GRPO(같은 문제의 여러 롤아웃을 비교해 상대적으로 나은 행동을 강화하는 강화학습 알고리즘) 보상으로 직접 사용함. 기존 방법의 한계도 뚜렷하게 정리됨. IGPO는 모델 자기 확신도로 보상을 정해서 학습이 진행되면 보상이 흔들림. CSO는 검증된 중요 스텝에만 크레딧을 주고 나머지를 무시함. SAPO는 엔티티 근접도로 평가해서 개별 결정의 정확 여부를 직접 못 봄. ABC는 정답 역추적 단서라는 고정 기준으로 모든 스텝을 평가하니 보상이 안정적이고 밀집함.

![](/images/2026-08-06-abseeker-answer-backtracked-credit-assignment/fig-5-p9.png)

4. 결과 표가 재밌음. Qwen3.5-4B 기반 ABSeeker가 BrowseComp 37.3%, BrowseComp-ZH(중국어 버전) 39.1%, xbench-2510 46.0%, GAIA-text 81.6%. 30B급인 Tongyi DeepResearch(40.0%), OpenSeeker(37.2%)과 나란히 하거나 넘음. 같은 4B인 QUEST-4B(30.0%), DR-Venus(29.1%)와는 확실한 격차. 그리고 여기에 컨텍스트 관리를 더하면 BrowseComp 37.3% → 55.3%, ZH 39.1% → 52.9%로 도약함. 크레딧 할당과 컨텍스트 관리의 효과가 독립적으로 쌓인다는 뜻임.

![](/images/2026-08-06-abseeker-answer-backtracked-credit-assignment/fig-6-p9.png)

5. 왜 작동하는지도 데이터로 보임. 8.5K 궤적의 스텝 점수 분포에서 실패 궤적의 약 10% 스텝이 1.0 이상의 보상을 받음. 기존 방법은 이 스텝들에 전부 0점을 줬을 것. 그리고 ABC-GRPO가 표준 trajectory-level GRPO보다 더 긴 검색 궤적을 만들면서도 정확도가 높음. 스텝별 보상이 탐색을 더 장려하기 때문. "길게 탐색하다 잘못되면 그 스텝만 페널티"라는 구조가 공격적 탐색을 안전하게 만드는 것임.

6. 내 실무 이식은 이렇게임. 첫째, 에이전트 훈련 데이터의 실패 궤적을 버리지 말 것. 정답을 아는 과제라면 역추적 채점으로 좋은 스텝을 살려낼 수 있음. 둘째, 스텝 채점 기준은 모델 자기 확신도 같은 가변 신호가 아니라 외부에서 고정된 기준(정답에서 복원한 단서)으로 둘 것. 보상 안정성이 학습 안정성임. 셋째, 스텝 보상 설계에서 "잘못 배제"에 큰 페널티(-0.8)를 주는 대칭 구조가 탐색을 촉진함. 넷째, 컨텍스트 관리(256K 제한, discard-all 5라운드)는 별개 축의 이득이라 크레딧 설계와 함께 독립 적용할 것. 한계는 있음. 정답을 알고 있는 훈련 데이터에 의존하는 방식이라 라벨 없는 도메인에 바로 못 쓰고, 검색 에이전트 도메인 검증이라는 점. 그래도 크레딧 할당 설계 원칙 자체는 일반적으로 이식 가능함.
