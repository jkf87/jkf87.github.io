# 웹툰이-자동으로-만들어진다

## 🎯 캐릭터 생성 프로세스

### 1. 4컷 만화 그리기

프롬프트에 캐릭터의 4장의 일러스트를 생성해달라고 요청합니다.

![4컷 만화 그리기 예시](images/webtooni-07-detailed-directions.png)

### 2. 투명 이미지 만들기

생성된 일러스트에서 투명 배경을 추출합니다.

### 3. 텍스트 레이어링

텍스트를 캐릭터에 자연스럽게 배치합니다.

### 4. 스케치 (Sketch)

캐릭터의 초기 스케치를 생성합니다.

### 5. 디테일드 디렉션 (Detailed Directions)

구체적인 디테일을 지시합니다:

```
1. 파란색 별 ⭐
2. 빨간색 삼각형 🔺
3. 초록색 사각형 ⬛
4. 분홍색 원 ⭕
5. 주황색 모래시계 ⏳
6. 보라색 무한 기호 ♾
7. ...
8. 부리부리 눈 👀
9. 엄지척 손가락 👍
10. 가위 ✂️
11. 파란색과 흰색 기린 🦒
12. "openAI"를 필기체로 작성
```

![디테일드 디렉션 예시](images/webtooni-08-character-consistency.png)

### 6. 캐릭터 일관성 유지

동일한 캐릭터가 여러 장면에서 등장하도록 요청합니다.

### 7. 완성된 캐릭터

최종적으로 완성된 캐릭터 이미지를 받습니다.

---

## 💡 팁

- **자연어 사용:** "화려한 학교 교복을 입고 웃는 소녀 캐릭터" 같이 구체적으로 묘사
- **참고 이미지 제공:** 원하는 스타일이 있다면 참고 이미지를 함께 제공
- **스타일 조합:** 여러 스타일 요소를 섞어 독착적인 캐릭터 생성
- **반복 생성:** 여러 버전을 만들어서 최고 결과물 선택
