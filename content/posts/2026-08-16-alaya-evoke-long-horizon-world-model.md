인터랙티브 월드 모델은 영구 기억, 즉각 반응, 장시간 생성을 동시에 만족해야 하는데 셋이 충돌함. [Evoke](https://arxiv.org/html/2608.13546v1)는 이걸 상태를 어디 두는가라는 시스템 설계 문제로 바꿔서 품. "상태를 외부로 내보내라"는 원칙이 에이전트 설계와 동일해서 정리함.

1. 배경. 기존 인터랙티브 월드 모델은 두 방식으로 세션을 유지함. 컨텍스트나 KV 캐시에 과거 프레임을 쌓으면 세션이 길수록 비용이 늘고, 짧게 자르면 싸지만 장면 일관성이 무너짐. 세션 길이와 기억 유지가 트레이드오프로 묶여 있었음.

2. 조치 1은 외부 지오메트리 메모리임. 장면 지오메트리를 카메라 포즈로 인덱싱된 외부 월드 상태 뱅크에 보관하고 디노이저 컨텍스트엔 짧은 관측만 남김. 현재 뷰에 필요한 정보만 뱅크에서 검색. 디노이저 컨텍스트 크기가 세션 길이와 무관하게 일정해지는 것.

3. 포즈 기반 리콜도 검증됨. 같은 포즈로 돌아오는 궤적에서 재방문 PSNR(원본과 재생성 영상의 픽셀 오차를 dB로 재는 지표로, 높을수록 원본에 가까움)이 리텐션 윈도우가 떠나 있던 시간을 덮으면 2.3-3.2dB 향상, 21개 비교 중 20개가 이 전이를 따름. 다만 플래토가 15.4-17.8dB라 픽셀 단위 재현은 아니고 알아볼 수 있는 수준의 복원임 — 주장의 경계를 스스로 명시한 게 좋음.

4. 조치 2는 롱호라이즌 교사 설계임. 저지연 학생의 상한은 교사가 정하니까 교사부터 길게 만든 것. 스파스 어텐션(청크 그룹화+원거리 검색+선형 어텐션 전역 상태)으로 활성화 메모리가 시간에 대해 선형 증가. 30초 분포 매칭 목적함수를 학생에게 전이.

5. 핵심 통찰은 이거임 — 짧은 윈도우에서는 그럴듯해 보이는 콘텐츠 드리프트가 긴 감독 구간에서는 드러남. 그 감독이 학생의 드리프트 저항으로 이어진다는 것. 짧게 평가해서 좋다고 한 게 길면 무너진다는 구조. 에이전트 벤치마크의 단일 태스크 평가가 긴 호라이즌 실전에서 무너지는 것과 같은 패턴임.

6. 결과. WBench 네비게이션 스플릿에서 평가된 소수 스텝 시스템 중 그룹 평균 1위. VBench-2.0(영상 생성 품질을 여러 축으로 채점하는 벤치마크)도 66.77로 10팀 중 1위. 약한 부분도 명시적임 — Navigation 78.63, Perspective 69.74는 최상위보다 낮음. 그리고 3-스텝 CFG(CFG는 classifier-free guidance, 생성 시 조건 반영 강도를 조절하는 기법) 없이 낸 값이라 비교군과 스텝 매칭은 아니라는 단서도 붙임.

7. 세션 안정성. 8개의 65.5분(2,619청크) 롤아웃에서 광도 통계가 안정되고 달아나는 품질 붕괴가 없음. 계산 쪽이 제일 실무적임 — 리텐션 예산이 차면 활성 풀은 더 늘지 않아 세션이 길어도 한 스텝 비용이 그대로. H200 한 장, 384×640에서 1.5초 청크를 2.11초에 생성. 2시간 연속 생성 데모도 있음.

8. 텍스트 제어의 경계도 측정해서 좋음. 세션 중간에 삽입된 지시는 미고정 콘텐츠면 67% 실현, 이미 지오메트리로 고정된 콘텐츠면 4%. 텍스트는 자유로운 콘텐츠를 다루고 고정된 지오메트리는 덮어쓰기를 막는다는 설계된 동작임. 이 경계를 아는 게 실사용에 중요함.

9. 여기서 문제제기. 이 패턴은 Light-Omni의 수면 시간 기억 통합, StateAct의 프로그램 상태 우선과 같은 방향임 — 긴 맥락을 모델 안에 쌓지 말고 외부 상태로 내보내고 필요할 때 검색. 처리량이 세션 길이에 묶이지 않게 하는 게 공통 목표임. 내 장기 실행 에이전트도 컨텍스트가 세션 길이에 비례해서 비싸지는 구조인지 점검할 것.

10. 적용 원칙. (1) 상태 저장소를 포즈/키 기반 인덱스로 외부에 둘 것. (2) 활성 컨텍스트는 고정 예산으로 유지할 것. (3) 재방문(같은 키로 돌아옴) 시 복원 품질을 측정해서 리텐션 정책을 조정할 것. (4) 교사/평가 윈도우를 실제 사용 길이에 맞출 것 — 짧은 윈도우 평가는 드리프트를 못 봄.

11. 한계 정리. 재방문 복원이 픽셀 충실 수준이 아님. 카메라 제어 경로가 최상위보다 약함. 교사 효과는 광도 안정성으로 한정 해석하는 게 정확함.

12. 결론. 영구 기억과 즉각 반응과 장시간 생성의 충돌을 상태 외부화로 풀었음. 세션 길이와 무관한 일정 스텝 비용이라는 성질이 시스템 설계의 핵심 수확임. 근데 그 대가로 고정된 것은 못 바꾼다는 경계가 생긴다는 것 — 유연성과 일관성의 트레이드오프가 어디로 이동했는지까지 봐야 한다는 결론임.
