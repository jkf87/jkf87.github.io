Berkeley와 MIT-IBM 팀이 웹 에이전트용 월드 모델의 학습 목표를 바꿨음. 기존은 다음 상태를 HTML·AXTree·요약문 같은 고정 형식으로 재생하는 supervised next-state prediction이었는데, 예측 표현이 같은 분기점의 다른 행동 결과와 구별되도록 훈련하는 predicted-state matching을 제안했음. 원문은 [arXiv:2609.02885](https://arxiv.org/abs/2609.02885).

1. 배경. 웹 에이전트는 대부분 현재 관찰과 이력으로 다음 행동 하나를 바로 고르는 반응형 구조임. 근데 최근엔 후보 행동을 여러 개 뽑고 월드 모델이 각 행동의 다음 상태를 예측하고 PRM(프로세스 보상 모델)이 순위를 매기는 test-time action selection 방식이 늘고 있음. 종래 월드 모델은 supervised next-state prediction으로 학습함.

2. 문제 지적이 날카로움. 이 목표가 하류 순위 결정과 어긋난다는 것임. 텍스트 요약 방식(WebDreamer)은 압축된 요약이 구별에 필요한 변경을 빠뜨릴 수 있고, 전체 구조 방식(WebWorld)은 AXTree 전체를 뱉으면 바뀐 부분이 그대로 있는 부분에 묻힘. 행동 선택에 쓰이는 예측 상태는 경쟁 행동 결과와 잘 구별될 때 가치가 있다는 게 핵심 통찰임.

![DWM 개요](/images/2026-09-03-dwm-discriminative-world-models-web-agents/fig-1-p2.png)

3. 방법. 현재 상태와 질의 행동이 주어지면 웰드 모델이 다음 상태 표현을 생성함. 그 표현을 고정 판정자(judge)에게 주고 진짜 결과 상태와 다른 행동의 결과 상태 중 무엇에 대응하는지 맞히게 함. 문자열 일치 대신 구별력 기준으로 학습하고 평가하는 것임. 월드 모델은 Qwen3-8B 파인튜닝, 판정자는 Qwen3-32B를 쓰고 검증에 GPT-4o와 Llama-3.1-70B로 바꿔봤음.

4. 데이터 구축이 재밌음. Go-Browse 궤적 2,839개에서 같은 브라우저 상태를 만나는 궤적을 병합하고 상태-행동 그래프로 변환한 뒤, 같은 상태에서 나가는 여러 행동과 결과를 분기 결정점으로 만듦. 최종 7,730개 결정점, 30,920쌍의 매칭 예제를 확보했음. 선형 궤적을 모아 분기점을 "합성"해내는 구조라서 내 데이터 파이프라인 설계에도 참고할 만함.

![판별적 월드모델 구조](/images/2026-09-03-dwm-discriminative-world-models-web-agents/fig-3-p5.png)

5. 결과 1. 홀드아웃 매칭 벤치마크에서 제안 모델이 GPT-4o, Qwen 계열, WebDreamer-7B, WebWorld-8B, 같은 데이터로 학습한 supervised baseline을 전부 이겼음. 판정자를 바꿔도 순위가 유지됐음.

6. 결과 2. WebPRMBench 행동 순위 결정에서 학습된 보상 모델이든 frozen ranker든 예측 상태를 붙이면 성적이 오르고 WebWorld-8B 상태보다 제안 모델 상태가 일관되게 좋았음.

7. 결과 3이 헤드라인임. WebArena-Lite 엔드투엔드에서 GPT-4o 정책 기준 ReAct 13.94%, Best-of-5 21.82%, 여기에 state matching 예측을 얹으면 28.48%까지 오름. 같은 정책, 같은 후보 샘플링에서 월드 모델의 학습 목표 하나를 바꿔서 2배가 넘는 차이가 났다는 뜻임.

8. 내 해석. 학습 목표 하나를 다운스트림 과제에 맞춰 바꿨더니 같은 데이터로도 성적이 올랐다는 게 이 논문의 가장 깔끔한 기여임. 이건 웹 에이전트뿐 아니라 평가·판단 모델 전반에 적용되는 원칙임. "정답과 얼마나 비슷한가"로 학습하지 말고 "오답 후보와 얼마나 구별되는가"로 학습하라는 것임. 내 자동화에서 결과 검증기를 만들 때도 정답 재현형 대신 대안 구별형으로 설계할 근거로 챙겼음. 특히 후보 행동을 여러 개 뽑고 하나를 고르는 구조에서는 예측의 가치가 "정확함"이 아니라 "구별력"에 있음.

9. 문제제기. 수치 비교가 전부 WebArena 계열 환경, GPT-4o 정책 기준이라 다른 환경·정책 검증은 열린 질문임(논문 한계 절도 인정). 매칭 평가가 LLM 판정자에 의존해서 모델 기반 프록시라는 한계도 남음. 판정자를 3종으로 바꿔 확인하긴 했지만 근본적으론 같음.

10. 결론. 월드 모델의 출력이 문자열로 얼마나 비슷한지가 아니라 행동 선택에 얼마나 기여하는지가 중요함. 학습 목표를 하류 과제에 정렬하는 것만으로 같은 데이터에서 성공률이 2배가 됨. 프로젝트 페이지는 [dhruvpendharkar.github.io/dwm](https://dhruvpendharkar.github.io/dwm/)에서 확인 가능함.
